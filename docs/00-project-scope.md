# 00 - Project Scope

## 1. Project Overview
Design of the network and ELV/ICT infrastructure for a fictional 4-storey office building (Ground + 3 floors) housing about 200 staff.

## 2. In Scope
| Area | Deliverable |
|---|---|
| Network | L2/L3 design, VLANs, inter-VLAN routing, IP plan |
| Security | Firewall zones, NAT, ACLs |
| Wireless | Corporate and guest Wi-Fi design |
| Physical | PoE, fiber uplinks, structured cabling |
| ELV | IP CCTV, access control, VoIP (conceptual) |
| Handover | BOQ, commissioning checklists, snag report, As-Built |

## 3. Out of Scope
- Real-world procurement and pricing negotiation
- Civil, electrical and HVAC design (only power/space requirements noted)
- Live deployment (design validated by simulation only)

## 4. Deliverables Checklist
- [ ] Topology diagrams (physical + logical)
- [ ] VLAN / IP allocation plan
- [ ] Switch and firewall configuration documentation
- [ ] PoE power budget
- [ ] Fiber / SFP selection plan
- [ ] Structured cabling layout
- [ ] BOQ
- [ ] Commissioning checklist, snag report, As-Built
